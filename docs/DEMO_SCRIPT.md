# Demo Video Script (≤3 min)

## 0:00–0:20 — Hook + Problem
"Meet [shop owner name], runs a kirana store in [town]. No forecasting, no reconciled books, finds out he's out of stock when a customer complains. That's most of India's 60M+ MSMEs."

## 0:20–0:40 — Solution one-liner
"This is [Product Name] — a multi-agent AI copilot built with OpenAI Codex. Five specialized agents work together to answer real business questions."

## 0:40–1:40 — Core flow (screen recording)
- Show dashboard, Business Health Score
- Type/speak: "I'm running low on rice, what should I do?"
- Show reasoning chain live: Inventory Agent → Finance Agent → Sales Agent → GST Agent → Recommendation
- Click "Why?" — show explainability
- Show confidence score, then Undo button

## 1:40–2:10 — Standout feature
Pick ONE: invoice OCR scan, or multilingual voice query, or Business Health Score breakdown. Show it working live, no cuts.

## 2:10–2:40 — Codex usage evidence
- Show Codex Activity Timeline page in-app
- Voiceover: "Every agent here was planned, built, self-reviewed and tested by Codex — logged step by step" — show one CODEX_LOG.md entry on screen

## 2:40–3:00 — Close
- Deployed link + repo link on screen
- "[Product Name] — built for Bharat's MSMEs, built by Codex."

## Recording notes
- Record 3 takes, pick best — don't try for one perfect take
- Screen record at 1080p min, voiceover clear audio (use a quiet room, not laptop mic if avoidable)
- Have seed data pre-loaded before recording — don't demo an empty state
- Test the exact query you'll speak/type beforehand — no live-debugging on camera
