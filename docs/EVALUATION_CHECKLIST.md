# Evaluation Checklist — Self-Score Before Submitting

Run this against the LIVE deployed link, not localhost, before Final Submit.

## Viability Gate (pass/fail — must clear before matrix scoring applies)
- [ ] Deployed link opens without error, no credentials required
- [ ] Core flow (ask question → multi-agent reasoning chain → recommendation) runs start to finish
- [ ] GitHub repo is public, commit history visible, matches what's demoed
- [ ] No broken buttons/dead links on the primary flow

## Technical Execution — 50%
- [ ] Code quality: no obvious dead code, consistent structure, agents isolated per AGENTS.md
- [ ] Architecture matches ARCHITECTURE.md (Orchestrator → Agents → Synthesizer)
- [ ] Clear evidence Codex genuinely built substantial portions (commit messages, CODEX_LOG.md)

## Impact & Problem Fit — 20%
- [ ] Problem statement is specific and real (not generic "AI helps business")
- [ ] Solution demonstrably moves a metric a kirana owner would care about (stock-outs, cash visibility, time saved)

## Use of Codex — 15%
- [ ] CODEX_LOG.md shows planning steps, not just single-shot generation
- [ ] At least one visible self-review/fix loop logged
- [ ] Multi-step execution evident (not just autocomplete-level snippets)

## Creativity & Originality — 10%
- [ ] At least one feature judges haven't seen in three other submissions (pick your standout — Health Score, reasoning chain, or invoice OCR)

## Completeness & Demo Quality — 5%
- [ ] Demo video ≤3 min, shows end-to-end flow AND Codex usage
- [ ] Project Description Google Doc complete: track, problem statement, technical stack
- [ ] Google Doc sharing set to "anyone with link"

## Submission Mechanics (don't lose points to process error)
- [ ] BlockseBlock: Create Project → correct track selected → Save & Next
- [ ] All mandatory links entered → Submit Now
- [ ] Both notes toggled on → Continue
- [ ] **Final Submit clicked** (drafts don't count)
- [ ] "My Projects" shows status = Submitted
